# Changelog

## 0.0.1

Initial release — a VSCode operator UI for the Sliver C2 framework.

- **Connections**: import operator `.cfg` files (stored in SecretStorage), connect/disconnect, multiple servers, live status bar.
- **Live trees** driven by the server `Events` stream: Sessions, Beacons, Jobs & Listeners, and a Server data browser (operators, implant builds, profiles, loot, credentials, hosts, websites, canaries).
- **Sessions** (context menu grouped into submenus): command console, interactive shell (tunnel-backed PTY), file browser (`sliver://` FileSystemProvider) + download/upload, screenshot, process list/kill/dump, recon (ifconfig/netstat), post-exploitation (execute-assembly/sideload/spawn-dll/migrate/shellcode/msf), privileges & tokens (getsystem/getprivs/impersonate/runas/make-token/rev2self), registry, services, environment, and pivoting (local & reverse port-forward, SOCKS5, pivot listeners, WireGuard).
- **Beacons**: queue commands, view/cancel tasks, open an interactive session.
- **Listeners**: start mTLS / HTTP / HTTPS / DNS / WireGuard / TCP-stager; stop jobs.
- **Implants**: generation form (listener→C2 picker, beacon options, save-as-profile), regenerate/delete builds, generate-from-profile.
- **Server data management**: add/delete credentials (with copy), add/download/delete loot, host details, website content, threat monitoring.

gRPC stubs are generated by `buf` from the pinned upstream Sliver tag (v1.7.3). Everything is bundled with esbuild; the `.vsix` ships no `node_modules`.
