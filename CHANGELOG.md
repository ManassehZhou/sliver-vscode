# Changelog

## 0.0.2

First release published to the VS Code Marketplace. Builds on the 0.0.1 baseline with:

- **Editable everything**: edit existing implant profiles (reopens the Generate form), create/edit HTTP-C2 profiles in a full config editor, edit credentials, rename loot, update served website content, and reconfigure a live session/beacon (reconnect / beacon interval & jitter) at runtime.
- **Richer implant generation**: C2 scheme insert buttons (mtls / http / https / dns / wg / tcp-pivot / named-pipe), an advanced per-endpoint C2 options builder that writes the `?query` string for you (driver incl. a free-text "Custom…" entry, host-header/domain-fronting, proxy, net/tls/poll timeouts, max-errors, DNS resolvers/retries), generate-stager from a profile, and **build on an external builder** (`--external-builder`: pick a registered builder, dispatch via GenerateExternal, then download from Implant Builds).
- **Raw gRPC console**: send any unary `SliverRPC` method over the authenticated channel — all 186 methods edited as JSON via the typed codec, or an arbitrary method path on a forked server with raw request bytes (hex/base64).
- **More coverage**: per-host IOC removal, WireGuard stop port-forward / SOCKS, HTTP long-poll timeout/jitter on listeners.
- **Fixes**: correct percent-encoding of C2 `?query` values (DNS resolver `+`, `&`/`=` in proxy creds); HTTP-C2 profile create-vs-update mode; clearer Server-tree loading errors (a build still compiling now shows a "Refresh" hint instead of a dead-end "error loading").

## 0.0.1

Initial baseline — a VSCode operator UI for the Sliver C2 framework.

- **Connections**: import operator `.cfg` files (stored in SecretStorage), connect/disconnect, multiple servers, live status bar.
- **Live trees** driven by the server `Events` stream: Sessions, Beacons, Jobs & Listeners, and a Server data browser (operators, implant builds, profiles, loot, credentials, hosts, websites, canaries).
- **Sessions** (context menu grouped into submenus): command console, interactive shell (tunnel-backed PTY), file browser (`sliver://` FileSystemProvider) + download/upload, screenshot, process list/kill/dump, recon (ifconfig/netstat), post-exploitation (execute-assembly/sideload/spawn-dll/migrate/shellcode/msf), privileges & tokens (getsystem/getprivs/impersonate/runas/make-token/rev2self), registry, services, environment, pivoting (local & reverse port-forward, SOCKS5, pivot listeners, WireGuard start/stop forward & SOCKS), rename, and reconfigure (reconnect interval / beacon interval & jitter) at runtime.
- **Beacons**: queue commands, view/cancel tasks, open an interactive session.
- **Listeners**: a full Start-Listener form — mTLS / HTTP / HTTPS / DNS / WireGuard / TCP-stager, with C2 domain restriction, website binding, HTTPS via ACME (Let's Encrypt) or custom cert/key, HTTP long-poll timeout/jitter, DNS canaries, and OTP; stop jobs.
- **Implants**: generation form (listener→C2 picker, beacon options, save-as-profile, edit existing profile), C2 scheme insert buttons (mtls / http / https / dns / wg / tcp-pivot / named-pipe) and an advanced per-endpoint C2 options builder (driver, host-header/domain-fronting, proxy, net/tls/poll timeouts, max-errors, DNS resolvers/retries) that writes the `?query` string for you; plus an advanced section — HTTP C2 profile (URL-path) selection, connection strategy, HTTP poll timeout, traffic encoders, canary domains, NetGo/evasion, and execution constraints (hostname / username / datetime / locale / domain-joined / file-exists); regenerate/delete builds, generate-from-profile, generate-stager from a profile (AES/RC4, compress, prepend-size), and build on an external builder (`--external-builder`: pick a registered builder, dispatches via GenerateExternal, then download from Implant Builds).
- **Server data management**: add/edit/delete credentials (with copy), add/rename/download/delete loot, host details + per-IOC removal, website content (add / update / remove), threat monitoring.
- **Server config**: create/edit HTTP-C2 profiles in a full config editor (server headers/cookies, implant user-agent/headers/url-params/path-segments/extensions and tuning), import/view profiles, certificate info, builders, crackstations, traffic encoders.
- **Raw gRPC console**: send any unary `SliverRPC` method over the authenticated channel — pick from all 186 methods (request/response edited as JSON via the typed codec) or hit an arbitrary method path on a forked server with raw request bytes (hex/base64). The escape hatch for endpoints the typed client doesn't wrap.

gRPC stubs are generated by `buf` from the pinned upstream Sliver tag (v1.7.3). Everything is bundled with esbuild; the `.vsix` ships no `node_modules`.
